# Vithusan S Portfolio

A modern personal portfolio website built with React, Vite, and Tailwind CSS. This portfolio is designed to present a developer profile, project work, technical strengths, and professional experience in a clean and engaging single-page layout.

## GitHub

- https://github.com/vithusan1225

## Features

- Responsive portfolio layout
- Light and dark mode support
- Smooth animations with Framer Motion
- Skills, project, experience, testimonial, and contact sections
- Easy content updates through a centralized data file

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Icons

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

The app will usually be available at:

```bash
http://localhost:5173
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Customize Your Content

Update portfolio details in:

- `src/data/portfolioData.js` for personal info, projects, skills, testimonials, and experience
- `src/components/` for section layouts and UI structure
- `src/App.jsx` for the overall page composition
- `src/index.css` for theme styling and visual design
