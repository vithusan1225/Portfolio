# Portfolio Website

A modern personal portfolio website built with React, Vite, and Tailwind CSS. It showcases profile information, skills, projects, work experience, testimonials, and contact details in a polished single-page layout.

## Features

- Responsive portfolio landing page
- Dark/light theme toggle
- Smooth motion animations with Framer Motion
- Skills, experience, project, and testimonial sections
- Contact section with social links
- Clean and customizable data-driven content structure

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- React Icons

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

### Run locally

```bash
npm run dev
```

The app will be available at the local Vite URL shown in the terminal, usually:

```bash
http://localhost:5173
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Customizing Your Portfolio

Edit the information in:

- `src/data/portfolioData.js` for personal info, skills, projects, experience, and testimonials
- `src/components/` for layout and section content
- `src/App.jsx` for overall page composition
- `src/index.css` for theme and styling adjustments

## Deployment

This project is ready to be deployed to static hosting platforms such as:

- Vercel
- Netlify
- GitHub Pages

Use the production build generated by:

```bash
npm run build
```
